# SkyShots 🚀

A classic vertical arcade sky shooter game built with Python and Pygame.

![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
![Pygame](https://img.shields.io/badge/pygame--ce-2.5+-green.svg)

---

## 🎮 How to Play

### Controls:
- **Move:** `Arrow Keys` or `W`, `A`, `S`, `D`
- **Fire:** `Spacebar` (hold for continuous firing)
- **Pause:** `P`
- **Restart (on Game Over):** `R`
- **Quit:** `ESC`

---

## ⚙️ Installation & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com/chandanm01206-dev/skyshots.git
   cd skyshots
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Alternatively: `pip install pygame-ce` or `pip install pygame`)*

3. **Launch the game:**
   ```bash
   python skyshots.py
   ```

## ✨ Features
- Fast-paced retro shoot 'em up gameplay
- Power-ups, multiple weapon spread modes, and dynamic shields
- Varied enemy waves and health mechanics
- Particle explosion effects and screen shake
- Score and high score tracking
